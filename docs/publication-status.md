# Publication status

The release excludes QuestionnaireToolkit, native file browsers, bundled installers, unrelated examples, and research data. The core uses neutral questionnaire interfaces and publisher namespaces. It includes offline documentation, licenses, an analytic example, rendering support, and reproducible exports.

Asset Store submission still requires Unity's decision on external Python execution, the Publishing Tools validator, publisher signing, listing artwork, dependency disclosures, AI assistance disclosure, and player deployment evidence. The exporter accepts `BO_UNITY_ORG_ID` for publisher signing. [Submission guidelines](https://marketplace.unity.com/publishing/submission-guidelines), [validation instructions](https://docs.unity.com/en-us/asset-store/publishing/asset-packages/upload).

The [validation record](validation.md) identifies the tested versions. Other operating systems, native installers, image encoder weights, and perceptual equivalence across pipelines require further evaluation.
