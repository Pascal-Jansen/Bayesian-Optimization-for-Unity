**Asset Store edition.** This manual is shared with the GitHub edition of BOforUnity. Three things differ in the package you imported from the Asset Store:

- Python is not bundled. Install Python 3.13 yourself before the first Play; the installers and installer scripts that sections 3 and 8.5 mention are not part of this edition. See [Getting Started](GettingStarted.html).
- QuestionnaireToolkit lives in `Assets/BOforUnity/QuestionnaireToolkit` instead of `Assets/QuestionnaireToolkit`.
- You import the package from the Package Manager instead of cloning the repository (section 3) or exporting it (section 11).
